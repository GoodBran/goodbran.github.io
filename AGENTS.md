# Guidelines

1. No one has time to read your article, write the first lines like they’re a TLDR.
2. Don't generate AI cover images. Covers are optional: only add `cover_image` when the post has a real photo or screenshot worth showing.
3. If a cover image is large (over ~200 KB), also add a small `thumbnail` (about 640px wide, WebP) for the post lists.
4. Keep to the Workbench theme in `_sass/_workbench.scss`: use its color tokens, JetBrains Mono for headings and UI, and IBM Plex Sans for body text.
